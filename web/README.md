# Temporal Voyager Portfolio

A cosmic noir portfolio website designed with a futuristic, space-inspired aesthetic.

## Design Philosophy

**Aesthetic Direction: Cosmic Noir**

This portfolio breaks away from conventional web design by embracing a bold, cinematic space thriller aesthetic. The design draws inspiration from superhero HUDs, sci-fi interfaces, time-travel narratives, and the vast beauty of galaxies.

### Key Features

- **Three.js Particle Galaxy Background**: An immersive 15,000-particle galaxy with spiral arms, nebula clouds, and distant stars
- **Glitch Typography**: Dynamic title effects with chromatic aberration
- **Holographic UI Panels**: Semi-transparent cards with glowing borders and hover effects
- **Parallax Mouse Interaction**: The galaxy responds to mouse movement for depth
- **Scanline & Vignette Effects**: Retro-futuristic visual atmosphere
- **Custom Color Palette**: Deep space blacks with neon cyan (#00f0ff) and magenta (#ff00ff) accents
- **Unique Typography**:
  - Display: Exo 2 (bold, futuristic)
  - Body: Rajdhani (technical, geometric)
  - Code: Share Tech Mono (distinctive monospace)

### Interactive Elements

1. **Warp Speed Easter Egg**: Konami code (↑↑↓↓←→←→BA) activates a warp speed visual effect
2. **Cursor Trail**: Subtle cyan particle trail follows mouse movement
3. **Scroll-Based Camera Depth**: Galaxy zooms as you scroll down the page
4. **Tab Switching**: Toggle between Open Source and Commercial projects
5. **Smooth Scroll Navigation**: Cinematic transitions between sections

### Performance Optimizations

- Automatic detection of low-end devices
- Reduced particle count for mobile
- Respects `prefers-reduced-motion` setting
- Throttled scroll and resize events
- Efficient Three.js rendering with fog for depth

### Sections

1. **Hero**: Bold introduction with animated stats
2. **Mission Briefing**: About section with avatar and tech stack
3. **Launch Pad**: Projects showcase (Open Source & Commercial)
4. **Contact Transmission**: Social links and communication channels

### Technologies

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **3D Graphics**: Three.js r128
- **Fonts**: Google Fonts (Exo 2, Rajdhani, Share Tech Mono)
- **PWA**: Manifest support for installable app experience
